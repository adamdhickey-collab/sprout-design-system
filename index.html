Accessibility · pairing guidance

AA is the minimum contrast rating permitted for normal text; AAA is the most legible pairing available; AA18 means a pairing only clears the bar for large text (18px+ regular, or 14px+ bold), graphical objects, and UI components. Never pair a foreground and background that isn't at least AA — check any new combination yourself with a WCAG 2.2 contrast tool before shipping it. Full spec: w3.org/TR/WCAG22.

AA
4.5:1 minimum for normal text — the accessibility floor for body copy anywhere in the system.
AAA
7:1 — the most legible pairings available. Prefer these where the choice is open.
AA18
3:1 — accessible only at large text (18px+ regular, 14px+ bold), for graphical objects, or for UI components. Not safe for body copy.
Don't use
Below 3:1. Not usable at any size — pick a different pairing.

Some secondary and soft swatches are narrower than they look: several — like soft-green and the light secondaries — clear only large-text (AA18) contrast against black or white, so reach for them behind large text or graphics, not body copy.

Core UI tokens · what to reach for

The primitives above are raw material. In practice, components reference a smaller set of semantic tokens that point at a primitive for a specific job — change the token's target once and every component using it updates together. These are the ones you'll use most when building a screen.

Token Swatch Use in the interface
--bg #F8F8F8 Page canvas — the back-most layer everything else sits on.
--surface #FFFFFF Cards, panels, modals, popovers — anything that reads as raised above the page.
--surface-input #FFFFFF Text field and textarea backgrounds — a recessed surface, kept as its own token so it can be tuned independently of cards.
--surface-pill #F3F4F3 Pills, chips, table header rows — compact, grouped UI.
--border / --border-input #DBDDDC Dividers, card outlines, input borders.
--text #101C16 Default body copy and headings — the highest-contrast foreground.
--text-soft #404945 Supporting copy and descriptions — one step down from primary.
--text-muted #58605C Helper text, timestamps, placeholders — the lowest-emphasis foreground.
--brand #00843D Primary buttons, links, the active nav item, focus rings — the one color reserved for "this is the primary action."
--brand-deep #023719 Hover / pressed state for brand elements, and text set on a light brand tint.
--on-accent #FFFFFF Text and icons placed on top of a --brand fill. Always pair the two — hardcoding white here is the most common dark-mode bug in this system.
--accent-gold #C7A86A Secondary accent — sparing use for decorative emphasis, never a primary action.

Status colors — --red-600 (error), --yellow-500 (warning), --green-600 (success), --blue-600 (info) — are primitives, not semantic tokens: they're pulled straight from the scales above rather than a --error/--success alias. Check contrast by hand any time one lands on a dark surface; see the Getting started checklist for the exact failure mode this catches.

UI terminology, in plain language

Surface
Any shape that holds content and sits above the page: a card, a modal, a menu, a tooltip. Sprout gives each kind its own token (--surface, --surface-pill, --surface-input) so they can be tuned independently.
Foreground
Whatever sits on top of a surface and needs to read clearly against it — text, icons, borders. See Themes for why foreground tokens have to re-point whenever the surface behind them does.
Accent / brand color
The one color reserved for "this is interactive, and it's the primary path": primary buttons, links, the active nav item, focus rings. Spend it deliberately — if everything is accented, nothing is.
On-accent
Shorthand for "the text or icon color that reads correctly on top of an accent fill." Reference --on-accent instead of hardcoding white — it's what lets a button's label survive the fill flipping color in Dark mode.
State / functional color
Color that carries meaning independent of brand: red for error, yellow for warning, green for success, blue for informational. These come straight from the primitive scales, not a semantic alias.
Primitive vs. semantic token
Primitives are raw values (--green-600). Semantic tokens point at a primitive for a specific purpose (--brand) and are what components should actually reference — full explanation on Getting started.

Both faces are licensed. Where Big Caslon isn't available — including the Figma library — EB Garamond stands in (it also ships as this site's live fallback), and Inter is used in place of Helvetica Now.

Touch targets · minimum hit area

Any control a finger has to land on gets at least 44 × 44 px, held by the --touch-target-min token. Set it as min-height and min-width rather than padding, so the target survives a short label. Pointer-only affordances on desktop may be smaller.

Material Symbols vs Material Icons. Sprout's default in Figma is Material Icons (Rounded), accessed through instance swaps. Material Symbols is the variable‑font version with optical sizing, weight, fill, and grade axes, supported through a Figma plugin. Use whichever fits your product, just keep the choice consistent within a surface.
